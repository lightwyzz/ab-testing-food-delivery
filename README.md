# A/B-тестирование в сервисе доставки

Анализ двух продуктовых экспериментов с использованием статистических методов.

## Задачи

**Тест 1 — фотографии блюд**

* сравнить 3 формата фотографий;
* проверить предпосылки ANOVA;
* определить статистически значимые различия;
* выбрать наиболее результативный формат.

**Тест 2 — кнопка заказа**

* сравнить старую и новую версии кнопки;
* оценить влияние версии кнопки и сегмента пользователя;
* проверить взаимодействие факторов.

## Методы

* One-way ANOVA
* Two-way ANOVA
* Levene test
* Normality test
* Tukey HSD
* Descriptive statistics

## Результаты

* **Формат фотографий:** квадратные изображения (B) показывают наибольшее среднее количество заказов.
* **Кнопка заказа:** новая версия показывает большее среднее количество заказов в обоих сегментах.
* Эффект новой кнопки различается между сегментами пользователей.
